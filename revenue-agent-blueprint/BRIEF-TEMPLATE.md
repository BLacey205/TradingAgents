# Revenue Agent Brief

Fill this in for one idea, then run it through the Revenue Agent Team with `/revenue-system` (or hand this file's contents to Claude Code directly and ask it to run the skill). You don't need every field perfect — the demand-research agent will sharpen anything vague. But the more specific you are here, the less generic the output.

## The idea (required)
[One sentence: what you'd help people do, or what you'd sell.]

## Who it's for (required)
[Be as specific as you can. Not "coaches" — "solo business coaches who already have 10-20 paying clients but no repeatable way to get the next 10."]

## The pain, in their words
[If you already know how your audience describes this problem themselves — quotes from DMs, calls, comments — put them here. If not, leave blank; research will find some.]

## What they're already trying
[Tools, competitors, or workarounds you know they use today, and where those fall short. Leave blank if unsure.]

## Constraints
- Price ceiling / floor you have in mind (if any):
- Format you want to deliver in (course, service, software, community, etc.), if you already have a preference:
- Anything you explicitly don't want to build:

## Existing assets
[Anything you already have that the system should build on rather than duplicate — an audience, a past offer, existing content, a waitlist.]

## Time horizon
[Are you validating this idea this week, or building the full system for a launch on a specific date?]

---

*Once filled in, this file is the single input the whole agent team runs on. Everything downstream — research, offer, content, funnel — traces back to what you wrote here, so don't pad it with things you don't mean.*
