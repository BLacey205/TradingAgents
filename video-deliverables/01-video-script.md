## 0:20–1:30 — The real gap: tools vs. systems, and the cost of not having one

[ON SCREEN: you, talking to camera — no slides yet]

> If you're a coach or a consultant, you're already using ChatGPT or Claude every single day. You're not behind on AI. I know you're not, because almost nobody watching this is.
>
> Here's what you're behind on: turning that daily use into a system that actually makes you money.
>
> Right now you've got a tool. A really smart one. But a tool that answers whatever you ask it is not the same as a system that takes one idea and hands you back positioning, an offer, content, and a way to capture leads — without you re-explaining your business every single time you open a chat window.
>
> And here's the part that should actually bother you: every week you don't have that system is a week a competitor spends turning the exact same tool you're using into a real offer. Same AI. Different result. The gap isn't the model. It's the system wrapped around it.
>
> So today I'm not going to explain what AI is. I'm going to build the system, live, on one idea — and you're going to watch it happen.

## 1:30–3:00 — Show the four-agent folder

[ON SCREEN: terminal + file tree, `.claude/agents/` expanded, each file opened briefly]

> Here's the whole mechanism. Four agents. Each one has exactly one job.
>
> [open `demand-research.md`] This one's only job is to find out if real people are already in enough pain to pay for this — not guess, find. It searches, it pulls real language, it tells me if the idea is weak.
>
> [open `offer-architect.md`] This one only turns validated demand into a priced offer — positioning, the mechanism, the ladder from free to premium.
>
> [open `content-angle.md`] This one only turns the offer into the hook and structure for a piece of content — a title, a thumbnail, a script outline.
>
> [open `conversion-path.md`] This one only builds what catches the person who got hooked — the lead magnet and the follow-up emails.
>
> [open the coordinator skill file] And this is the piece that actually makes it a team instead of four disconnected prompts — it runs them in order, and each one has to read the previous one's real output file before it's allowed to write anything. No agent gets to guess at a stage it wasn't handed the inputs for.
>
> That's the whole unique mechanism. Not "AI helps me brainstorm." A chain, where each link has to show its work to the next one. Same reason a real team beats one overworked generalist — specialization, with a handoff.
>
> One idea goes in the top. Watch.
