# Titles and Thumbnail Copy

## Title

**Primary:** I Built an AI Agent Team That Turns One Idea Into a Revenue System

**Backups:**
1. Stop Using AI Like a Search Engine. Build This Instead.
2. The 4-Agent System That Replaced My Marketing Team
3. One Idea In, A Full Offer Out.
4. You're Not Behind on AI. You're Missing This System.

**Notes on choosing:**
- Primary names the mechanism (agent team) and the outcome (revenue system) in one line — use it as the default.
- Backup 1 and 4 work best for cold/algorithmic traffic to this audience, since they open with the viewer's own excuse ("I use AI every day") rather than the mechanism — test one of these as the thumbnail-adjacent title if primary underperforms in the first 48 hours.
- Backup 2 and 3 are the sharpest for retargeting an audience that already knows who you are — they assume context primary doesn't need to supply.

## Thumbnail text options

Pair exactly one of these with the title — don't stack more than one on the thumbnail itself, and don't repeat a word already in the title.

1. "4 AI AGENTS"
2. "1 REVENUE SYSTEM"
3. "STEAL THIS"
4. "BUILT LIVE"

**Recommended pairing:** "4 AI AGENTS" (top) + "BUILT LIVE" (bottom) — states the mechanism count and the proof claim (live, not pre-made) without duplicating the title's wording. Use "STEAL THIS" as the swap-in variant for a thumbnail A/B test; it trades mechanism-clarity for curiosity/permission, which tends to outperform with audiences already warm to the creator but underperform cold.

**Visual note:** the brief's "what must be shown" rule applies to the thumbnail too — use a real screenshot of the actual `.claude/agents/` folder or real terminal output as the background, not a stock graphic or a generic AI/robot image. The thumbnail should look like evidence, not an ad.
