## Email 2 — Fix the #1 setup mistake

**Subject:** The mistake that makes people think it's broken

If you installed the Blueprint yesterday and ran it, only to get generic output or an error that the agents don't exist — I already know what happened.

You didn't restart Claude Code after copying the files in.

Subagents and skills only get loaded at startup. If you install them into a session that's already running, Claude Code doesn't see them — so you ask it to run the revenue-system skill, and it either can't find it or tries to fake its way through the job as one generic prompt instead of four agents handing off real files to each other. That's not the system failing. That's the system never actually starting.

Fix: close Claude Code completely, reopen it in the folder where you installed the `.claude/` folder, and check that the four agent files show up before you run anything.

Once that's confirmed, you're ready for the real test — which is what tomorrow's email is about.
